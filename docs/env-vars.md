# Environment Variables

Normal guided setup supplies only public deployment values and captures the
ntfy token on a verified runner-owned page. Users should not hand-author these
variables.

## Guided hosted runner

`PULSE_SETUP_PUBLIC_KEY`

Public SPKI-encoded Ed25519 key created by Workshop for one setup. The runner
publishes its fingerprint in the manifest and verifies Workshop’s pairing
signature. An existing deployment can add this value to enable safe migration.

`PULSE_NTFY_TOPIC`

Private authenticated topic reserved by the user. Sensitive personal routing
data; keep it out of the public repository even though it is not sufficient as
authentication by itself.

`PULSE_NTFY_SERVER`

HTTPS notification-service origin, normally `https://ntfy.sh`.

`PULSE_SETUP_RETURN_URL`

Non-secret Workshop return value for the setup session.

`URL`

Canonical production site URL supplied by Netlify. Pulse does not ask the user
to hard-code it.

`PULSE_NOTIFY_PROVIDER`

The current production adapter is `ntfy`. `console` is allowed only for local
demos.

The guided path does **not** place the ntfy token, client credentials, action
signing material, reminders, or history in template environment variables.
Those values are captured or generated by the runner and stored privately.

## Legacy migration variables

Existing deployments may still contain `PULSE_NTFY_TOKEN`, `PULSE_API_TOKEN`,
and `PULSE_NOTIFICATION_ACTION_SECRET`. The runner accepts the legacy API token
during migration and treats an existing ntfy token as configured. New guided
deployments use per-Mac credentials and runner-owned private storage instead.

## Advanced local-file runner

`PULSE_CONFIG_PATH` — absolute path to private `pulses.yaml`.

`PULSE_STATE_PATH` — absolute path to private state JSON.

`PULSE_PRIVATE_ROOT` — absolute private root containing those files.

`PULSE_RUNNER_MODE` — `demo` for public smoke tests or `production` for a real
runner.

`PULSE_RUNNER_INTERVAL_MS` — polling interval for the local watch runner;
defaults to `60000`.

`PULSE_RUNNER_HEALTH_PATH` — optional private heartbeat path.

`PULSE_RUNNER_TIMEZONE` — optional operator hint; definitions carry their own
IANA time zone.

`PULSE_API_HOST` / `PULSE_API_PORT` — local API bind values, defaulting to
`127.0.0.1:8787`.

`PULSE_API_ALLOWED_ORIGINS` — legacy browser allowlist. It is not
authentication and should remain blank for Workshop’s native proxy.
